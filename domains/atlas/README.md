# Atlas domain pack

Atlas is an interactive visual knowledge platform for **learning material**. Figures are one
format among many: a text note, a PDF page, a slide, a video frame, a link or a small dataset can
all become a lesson. The host keeps the source checkout and its media external and stores paths
plus digests.

## Import

Open the workspace, then use the **drop zone** to **drop anything** the lesson needs. The pack
extracts text, validates a `VisualAnalysis`, and stores the result under the external data root.
Offline mode renders the same lesson without a model call and labels it `fixture`.
